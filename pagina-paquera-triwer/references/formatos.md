# Escolha do formato

Este arquivo serve só para decidir com o aluno. Depois da escolha, leia apenas
`modo-html.md` ou `modo-react.md`.

| | HTML único | Projeto React |
|---|---|---|
| Para quem | Quem nunca programou, ou vai colar a página num construtor/hospedagem | Quem tem alguém técnico para implementar, ou já usa Node |
| Ambiente | claude.ai e Claude Code | Só Claude Code |
| Como abre | Dois cliques no arquivo | `npm install` e `npm run dev` |
| Como publica | Sobe o arquivo e a pasta `img/` em qualquer hospedagem | Compila e sobe a pasta `dist/` |
| Animações | Entrada ao rolar, títulos palavra por palavra, contadores, carrossel, livro 3D, calculadora | As mesmas, com física de mola e transições mais suaves |
| Edição depois | Texto direto no HTML | Textos nos componentes, links e preço num `config.js` |

## Como perguntar

"Tu prefere receber um arquivo que abre direto no navegador e sobe em qualquer
hospedagem, ou um projeto de código para alguém técnico implementar no teu site?"

Se a resposta for "não sei", vá de HTML único. Dá para converter depois.
